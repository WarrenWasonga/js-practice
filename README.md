# JavaScript String Manipulation & Practice Labs

Welcome to my repository! This project contains JavaScript scripts created while learning core web development concepts on freeCodeCamp.

## 📝 Projects & Scripts Included

- **`stringinspector.js`**: Explores string search and extraction methods like `.includes()`, `.indexOf()`, and `.slice()`.
- **`sentencemaker.js`**: Uses string concatenation, template literals, and variable reassignment to dynamically create stories.
- **`greetingbot.js`**: Interactive script utilizing JavaScript functions and string formatting.
- **`javascripttriviabot.js`**: Exercises using boolean logic, string comparison, and conditional console output.
- **`teacherchatbot.js`**: Interactive console chatbot practicing string methods, variables, and automated text responses.

## 🧠 Concepts Practiced

- **JavaScript Fundamentals**: Variable declarations (`let` vs. `const`), variable reassignment, and boolean logic.
- **String Methods**: Index positioning (zero-indexed counting), `.includes()`, and `.slice()`.
- **Template Literals**: Using backticks (`` ` ``) and `${variable}` placeholders for clean string formatting.
- **Version Control**: Staging files, writing descriptive Git commit messages, and syncing local VS Code files with GitHub.
